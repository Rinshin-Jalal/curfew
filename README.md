# Curfew

A hard bedtime lock for an Android phone and a Mac. Every night, on a schedule you pick, both lock until morning.
One tap on SLEEP (phone, Mac, or an iPhone Shortcut) locks both right now. You run your own tiny server on
Cloudflare, so nothing about your nights goes anywhere else. What happens at night:

- **Fresh words**: the unlock screen draws 8 random words (about 60 characters) every time it opens, so there's
  nothing to memorise. You type them by hand (no paste), it bumps the shame counter, and it buys a 15 minute break,
  two a night at most, then the lock comes back by itself. Loosening the rules costs a fresh set too. Rules can't be
  changed during a break.
- **Quiet nights**: while locked, the phone snoozes notifications from apps that aren't allowed until the lock ends,
  and allowed apps still make a sound. Calls ring and alarms go off. The Mac mutes its sound.
- **The judge**: once both breaks are used, it's the only way out. Write why you need the phone right now, and an
  open model on Workers AI (GPT-OSS 120B) decides.
  It's told to be fair: a concrete task that needs the device before the lock ends (a production incident, a ride
  home, a 2FA code or payment) gets 5 to 30 minutes, then the lock comes back. Anything a call or text covers,
  anything vague, "just checking", and a story that keeps coming back on other nights get a no. Everything you
  write in one night is read as one story, so explaining better isn't held against you. `npm run eval` in server/
  runs it on 14 cases. It doesn't count as an early unlock. At most 3 asks a night,
  10 minutes apart, each decided on its own, and it sees the past week of asks.

```
server/   Cloudflare Worker + one Durable Object (state + every device's socket) + Workers AI for the emergency judge.
android/  Expo app (React screens) + modules/sleep-native (Kotlin: accessibility blocker, overlay, screen-off,
          QS tile, widget, exact alarms, sync). No hand-edited android/ folder: it's generated by prebuild.
mac/      Swift menu-bar app (SwiftPM): overlay on every screen, kiosk mode, muted sound, /etc/hosts block. Apps stay open.
shared/   SleepState type + the fonts (Newsreader for headlines and the clock, Instrument Sans for the interface, both OFL).
          The home screen shows tonight's real moon: 30 frames (shared/moon, copied into the native module's drawables) rendered from NASA's LRO color
          and elevation maps (CGI Moon Kit, svs.gsfc.nasa.gov/4720, public domain), which also give the app icon.
docs/     limits.md (every known bypass), play-accessibility-declaration.md
```

Each device decides "am I locked" from its cached state + its own clock, so the lock never waits on the server.
The same schedule rules exist three times (`server/src/logic.ts`, `Schedule.kt`, `Schedule.swift`), each with
tests for DST, reboot re-arming and taps.

## Setup

It's built for one person: one server, one token, your devices. Each person who wants it deploys their own copy.
You need a Cloudflare account (Workers, one Durable Object and Workers AI), Node, Android Studio's SDK and `adb`
for the phone, and Xcode's command-line tools for the Mac. There's no Play Store or App Store build: Google limits
apps that block other apps through Accessibility, and the Mac side needs a sudo rule, so you build both yourself.

### 1. Server

```bash
cd server && npm install
npx wrangler deploy                      # prints https://sleep-sync.<you>.workers.dev
TOKEN=$(openssl rand -hex 24); echo "$TOKEN"          # keep it: the phone and Mac need it
echo "$TOKEN" | npx wrangler secret put APP_TOKEN
```

Local instead: `cp .dev.vars.example .dev.vars` (set APP_TOKEN; the judge's Workers AI binding runs remotely even in dev), `npx wrangler dev --port 8788`, and
`adb reverse tcp:8788 tcp:8788` so the phone reaches it over USB.

### 2. Android

```bash
cd android && npm install
cp .env.example .env                     # EXPO_PUBLIC_API_URL = the workers.dev URL, EXPO_PUBLIC_APP_TOKEN = APP_TOKEN
npx expo prebuild --platform android
cd android && ./gradlew app:assembleRelease && adb install -r app/build/outputs/apk/release/app-release.apk
```

Then in the app: **schedule** (Turn on Curfew: nothing is enforced until then), **permissions**
(all seven; if Accessibility is greyed out: App info → ⋮ → Allow restricted settings), and optionally
**allowlist**. Add the **Curfew** Quick Settings tile and home-screen widget for one-tap locking.

### 3. Mac

```bash
cd mac && ./install.sh https://sleep-sync.<you>.workers.dev <APP_TOKEN>
```

Builds `Curfew.app` into /Applications, runs it from a LaunchAgent (KeepAlive: quit it and it's back in ~2 s),
and installs one root-owned script plus a sudoers rule that lets the app run exactly `sleep-hosts on|off`
(asks for your password once). Menu bar moon: status, **Sleep now** (⌃⌥⌘S anywhere), and
**Sleep the Mac at lock start** (off by default: it blacks out and sleeps the display instead).
To edit the blocked sites, change the list in `mac/sleep-hosts` and re-run install. `./uninstall.sh` removes everything.

### 4. iPhone Shortcut (one tap from anywhere)

Shortcuts → new → **Get Contents of URL**: `https://sleep-sync.<you>.workers.dev/sleep/tap`, Method POST,
Header `authorization: Bearer <APP_TOKEN>`. Add it to the Home Screen or Action button. Both devices lock within
about a second if they're online. A Mac app intent couldn't run from an iPhone anyway, so this replaces AppIntents.

## Tests

```bash
cd server && npm test                                          # schedule/DST/tap/put/emergency rules
cd android/android && ./gradlew :sleep-native:testDebugUnitTest
cd mac && xcrun swift test
```

## API

`GET /sleep`, `PUT /sleep {schedule?, allowlist?, tz?, phrase?, currentPhrase?}` (423 while locked; changing
rules needs the current phrase; mode can't be set here), `POST /sleep/tap {until?}`,
`POST /sleep/unlock` (the device checked the typing; 2 a night), `POST /sleep/appeal {reason}` (only after both breaks; Workers AI judges; approval returns `{approved, minutes,
reply, state}`), `GET /sleep/stream?t=TOKEN` (WebSocket, pushes the full state on every change).
All take `authorization: Bearer APP_TOKEN`. Single user: no accounts, no JWT.
